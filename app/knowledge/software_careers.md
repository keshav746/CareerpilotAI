# Software career preparation

Frontend developers work with HTML, CSS, JavaScript, browser accessibility, responsive layouts, APIs, and often React. Backend developers work with Python or Java, databases, authentication, APIs, testing, and deployment. Full stack developers connect frontend interfaces, backend services, and databases. Building and documenting an end-to-end project is useful evidence of skills.

A data analyst commonly needs SQL, spreadsheet analysis, descriptive statistics, data cleaning, data visualization, and communication. Python and tools such as pandas and Power BI can support analysis. Portfolios should explain the data source, assumptions, analysis process, and limitations.

For technical interviews, prepare to explain architecture, tradeoffs, debugging, testing, teamwork, and measurable project outcomes. For behavioral questions, describe the situation, your task, actions, and results. Never invent projects or credentials on a resume.
